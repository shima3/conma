2026/4/24 Fri
bug: 保存した値を取得できない。
__Dict_put__ dict "Key A" "Value A" ,()
__Dict_lookup_or__ dict "Key A" onMissing ,(value)

原因：eval_expr が String 値をAST ノード（["String", sinfo, '"text"']）として返すため、同じ文字列でもステップをまたぐと別 Python オブジェクトになります。_values_equal が isinstance(a, str) のチェックしか持っていなかったため、String AST ノードは a is b（恒等比較）で評価され、常に False になっていました。
def _values_equal(a, b):
---
    if isinstance(a, str) and isinstance(b, str):
        return a == b
---
コード中の文字列の場合、a, b には AST ノードが渡される。
同じ文字列でも記載された位置が違うと異なるオブジェクトである。

修正：String AST ノードをインデックス2の内容で比較するよう修正しました。
---
    if (isinstance(a, list) and a and a[0] == "String" and
            isinstance(b, list) and b and b[0] == "String"):
        return (len(a) > 2 and len(b) > 2 and a[2] == b[2])
    if isinstance(a, str) and isinstance(b, str):
        return a == b
---
