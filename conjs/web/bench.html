ConJS のホストの関数を測る

conjs/bench のプログラムを、wasm 版の ConMa の VM で、ホストの JavaScript の関数あり（ふつう）と、なし（CONMA_NO_HOSTJS。ConMa だけで動かす）で動かし、 1 回の時間を比べる（docs/dev/CONJS-HOST-PLAN.md の 32 節、段階 H7）。1 回の時間は、（時間 − 大きさ 0 で動かした時間）÷ 大きさ。 ホストの関数なしは遅いので、大きさを分けた。出力は、なしの大きさで、ありとなしを比べる。 ?hostreport を付けると、ホストで動いた関数を、ブラウザのコンソールに出す。 星ひろい、canvas の見本。
