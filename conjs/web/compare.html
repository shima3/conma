星ひろい：ConJS と JavaScript

同じゲーム「星ひろい」を、3 つの書き方で書いたもの。2 つを選んで並べる。 黄色の行は、待つ所（ConJS の nextEvent、sleep、host.wait、spawn と join。JavaScript の await、Promise、setTimeout、setInterval、 requestAnimationFrame と、その止め方）。

  • ConJS（stars.con.js）：画面の順はふつうのループ、おばけは spawn した処理。待つ呼び出しは、ふつうの呼び出し。 端末で遊ぶための分（端末に描く paintTerm など）も入っている。
  • JavaScript、イベント駆動（stars-events.js）：画面ごとの状態の変数と、キーの受け手の中の分岐。 おばけの setInterval と clearInterval。
  • JavaScript、async/await（stars-async.js）：ConJS 版と同じ形。待つ所すべてに await が要り、 それを呼ぶ関数はみな async になる。キーを待つ Promise は自分で作る。
